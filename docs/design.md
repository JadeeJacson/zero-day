# 零日（ZERO-DAY）设计文档

> 一款潜入题材的卡牌肉鸽。你是一名独立网络潜袭者，带着一套手搓程序库和几件二手义体，
> 受掮客委托潜入企业数据堡，逐层击穿安保节点，把核心数据拽出来。

- v0.1 状态：**迷你整局可玩**（4 区段 × 1 战 + 黑市 + 胜负结算）
- 调参入口：`src/core/run.ts`（区段/经济/人性）、`src/core/cyberware.ts`（义体）、`src/core/techniques.ts`（手法）

## 3. 手法表（核心组合系统）

威力 = 手法基准 + Σ参与程序强度；**穿透 = 威力 × 效率**。
攻击时从所选 1–5 张中**枚举全部子集，自动取穿透最高的手法**结算（同分取更稀有者），
因此永远存在合法解——不会出现「这手牌啥也不是」的死区。

| 手法 | 条件 | 基准 × 效率 |
| --- | --- | --- |
| 完全潜袭 Full Dive | 5 张同纪律且强度连续 | 120 × 8 |
| 数据洪流 Data Flood | 5 张同纪律 | 70 × 5 |
| 螺旋降维 Spiral Descent | 5 张强度连续 | 60 × 4 |
| 阵列冲击 Array Strike | 4 张同纪律 | 40 × 3 |
| 梯度瀑布 Cascade | 4 张强度连续 | 40 × 4 |
| 四象全谱 Full Spectrum | 4 张、四纪律各一 | 35 × 4 |
| 聚焦脉冲 Focus Pulse | 3 张同纪律 | 25 × 3 |
| 链路穿透 Link Pierce | 3 张强度连续 | 25 × 2 |
| 散点扫描 Scatter Scan | 3 张纪律互异 | 20 × 2 |
| 共鸣脉冲 Resonance | 2 张同纪律 | 10 × 2 |
| 并行齐射 Parallel Volley | 2 张任意 | 12 × 1 |
| 单点探测 Lone Probe | 1 张任意 | 5 × 1 |

由此长出三类 build 原型：**均质流**（堆同一纪律 → 洪流/阵列）、
**链式流**（追连续强度 → 螺旋/瀑布）、**散点流**（四色齐全 → 全谱）。义体选購围绕流派走。

## 4. 义体与人性（庞德史密斯母题的转译）

义体 = 被动被动件，最多装 5 件。**每件有人性损耗，买入即永久**（卖出只返半价，人性不退还）。
损耗是累计的，跨过阈值立刻受罚：

- 累计 −15：攻击窗口 −1（下限 2）
- 累计 −30：重编译 −1（下限 1）
- 累计 −45：手牌上限 −2（下限 5）

这就把「买买买」变成资源决策：义体是力量，也是你和「人」之间渐行渐远的账单。
v0.1 共 13 件义体，定义见 `src/core/cyberware.ts`，钩子分两级：`onCard`（逐张参与牌）与 `onPlay`（每次攻击一次）。

## 5. 区段、节点与固执协议

每区段在三个候选节点里**选一个**下手，打穿任意一个即结算进黑市：

| 节点 | 阈值 | 报酬倾向 |
| --- | --- | --- |
| 外围接入点 Perimeter | 区段基值 ×1 | 低 |
| 中继枢纽 Relay Hub | ×1.5 | 中 |
| 核心主机 Core Host | ×2 + 固执协议 | 高 |

| 固执协议 | 效果 |
| --- | --- |
| 铁幕协议 Iron Wall | 核心主机阈值额外 ×1.25 |
| 静默封锁 Blackout | 本战无法重编译 |
| 蜂群协议 Swarm | 每次攻击后随机熔断 1 张未使用手牌 |

每局随机一家企业（玄鸦网络 / 白鲸数据 / 赤瓷重工），区段基值 300 / 600 / 1200 / 2200。
战基本参数：手牌 8、攻击窗口 4、重编译 3（受人性惩罚削减）。

## 6. 经济

- 开局 ¤40；击穿报酬见上表；战后利息 = 每 50 结余 +10，上限 40
- 义体 ¤80–130，卖出返半价；重掷货架 ¤50 起，每次 +10
- 利息机制鼓励「见好就收」与「攒钱吃息」的博弈——这是从桌游的接活报酬文化里长出来的紧张感
