# 零日 ZERO-DAY

潜入题材卡牌肉鸽。赛博朋克世界观 + 庞德史密斯桌游机制母题 + 吉布森式文本，
玩法层（手法组合系统）完全原创，不照搬任何现有游戏。

> 一句话：选牌组成「手法」，威力 × 效率击穿节点完整性；义体给你力量，也扣你的人性。

当前版本 **v0.3（迷你整局 + 牌组改造）**：4 区段 × 三选一节点、12 种手法、13 件义体、
固执协议、利息经济、程序工作台、移动端手牌和胜负面板。设计细节与原创性边界见 [docs/design.md](docs/design.md)。

## 运行

```bash
npm install
npm run dev      # 开发
npm test         # 44 个单元测试
npm run build    # tsc 检查 + 产物到 dist/（gzip 约 8 KB）
npm preview      # 预览构建产物
```

## 结构

```
src/core/     纯逻辑，零 DOM 依赖，全部可单测
  cards.ts      程序卡：4 纪律 × 强度 1–10
  techniques.ts 手法判定 + 最优子集搜索
  cyberware.ts  义体定义（数据驱动，加一行=加一件）
  scoring.ts    计分引擎，产出事件流水供动画播放
  run.ts        对局状态机：区段/节点/经济/人性/牌库改造
src/main.ts   DOM 界面与结算动画
tests/        techniques / scoring / run 三组测试
```

## 范围契约（v0.3）

**做**：迷你整局可玩、核心逻辑全单测、零外部资源、牌库强化/重写/隔离、首次引导、移动端适配。

**不做**（防止越做越大，见 design.md §9 再谈）：存档、塔罗/星球类比物、
角色流派、无尽模式、联机和外部美术资源。
