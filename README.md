# 零日 ZERO-DAY

潜入题材卡牌肉鸽。赛博朋克世界观 + 庞德史密斯桌游机制母题 + 吉布森式文本，
玩法层（手法组合系统）完全原创，不照搬任何现有游戏。

> 一句话：选牌组成「手法」，威力 × 效率击穿节点完整性；义体给你力量，也扣你的人性。

当前版本 **v0.4（事件与流派）**：4 区段 × 三选一节点、12 种手法、13 件义体、
固执协议、企业特性、利息经济、程序工作台、6 个区段事件、4 种开局流派、seed 复现、
移动端手牌和本机战绩。设计细节与原创性边界见 [docs/design.md](docs/design.md)。

## 运行

```bash
npm install
npm run dev      # 开发
npm test         # 47 个单元测试
npm run build    # tsc 检查 + 产物到 dist/
npm preview      # 预览构建产物
```

## 结构

```
src/core/     纯逻辑，零 DOM 依赖，全部可单测
  cards.ts      程序卡：4 纪律 × 强度 1–10
  techniques.ts 手法判定 + 最优子集搜索
  cyberware.ts  义体定义（数据驱动，加一行=加一件）
  scoring.ts    计分引擎，产出事件流水供动画播放
  events.ts      区段事件数据：事件与二选一风险/收益
  run.ts        对局状态机：区段/节点/事件/经济/人性/牌库改造
src/main.ts   DOM 界面与结算动画
tests/        techniques / scoring / run 三组测试
```

## 范围契约（v0.4）

**做**：迷你整局可玩、核心逻辑全单测、零外部资源、牌库强化/重写/隔离、区段事件、
开局流派、seed 复现、首次引导、移动端适配和可展示的本机战绩。

**不做**（防止越做越大）：云端账号/存档、塔罗/星球类比物、无尽模式、联机和外部美术资源。
